# プロジェクト管理画面

## 概要

プロジェクト一覧・詳細・管理に関わるコンポーネントを定義する。

## コンポーネント一覧

| コンポーネント | 責務 |
|----------------|------|
| Projects（一覧） | 公開用のプロジェクトカード一覧 |
| ProjectCard | カード要約（名前・概要・役割・技術・成果）と詳細リンク |
| ProjectDetail | 概要〜成果のセクション表示 |
| UserProjectsManagerPage | Users からの管理画面シェル |
| UserProjectsManager | 作成フォームと一覧上の編集・削除 |
