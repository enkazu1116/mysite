# プロジェクトドメイン

## スコープ

| 含む | 含まない（現時点） |
|------|-------------------|
| プロジェクトの CRUD | 技術マスタ（techs）との紐づけ |
| ユーザー単位の一覧・管理 | 認証付き管理 API |
| 公開一覧・詳細の取得 | 外部ポートフォリオ連携 |

## 主要エンティティ

- **Project**: 参画プロジェクト。概要、役割、チーム規模、使用技術、課題、工夫 / 意思決定、成果を保持する。

実装の型定義は `backend/src/features/projects/types/` を参照。

## 所有関係

Project は User に属する（`user_id` FK）。認証導入前はクエリ / ボディの `userId` で管理対象を指定する。
