# 4. プロジェクト管理

## 目的

参画してきたプロジェクトの概要と、自身の役割・経験をポートフォリオとして公開・管理する。

プロジェクトドメインの責務:

- プロジェクト概要・役割・チーム規模・使用技術の管理
- 課題・工夫 / 意思決定・成果の記録
- 公開一覧・詳細、およびユーザー単位の管理 API の提供
