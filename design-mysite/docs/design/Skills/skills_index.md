# 1. スキル管理

## 目的

システム開発者の技術スキル・経験を管理し、ポートフォリオとして公開する。

スキルドメインの責務:

- 言語・技術スタックごとのスキル情報の管理
- 経験月数・レベル・詳細説明の保持
- 訪問者向けの読み取り専用 API の提供
