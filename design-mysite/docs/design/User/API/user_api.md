# User API

## 概要

ユーザードメインの HTTP API を定義する。

## エンドポイント一覧

| メソッド | パス | 説明 |
|----------|------|------|
| POST | `/user/v1.0.1/create` | 管理者プロフィールを作成する |
| GET | `/user/v1.0.1/get` | プロフィールを取得する |
| PATCH | `/user/v1.0.1/update` | プロフィールを更新する |
| DELETE | `/user/v1.0.1/delete` | プロフィールを削除する |

## 処理一覧

| 処理 | 説明 |
|----------|------|
| User登録 | サイト利用者の登録 |
| User取得 | サイト利用者のプロフィール取得 |
| User編集 | サイト利用者情報の編集 |
| User削除 | サイト利用者の削除 |

## 処理詳細
### User登録
#### 概要

サイト利用者アカウントの作成、登録を行う。

#### 処理フロー

1. リクエスト（`CreateUserRequest`）の検証
    - 名前: 必須・30文字以内
    - 自己紹介文: 任意・200文字以内
    - URL系: 空文字は `null` に変換
2. ユーザー名の重複チェック
3. User ID の採番
4. 永続化用モデル（`UserRow`）の組み立て（`AuditMetadata` 含む）
5. DB へ保存
6. 作成結果を返却

### User取得
#### 概要

サイト利用者のプロフィールを取得する。

#### 処理フロー

1. 取得対象の User ID を受け取る
2. DB から対象ユーザーを検索
3. 存在しない場合はエラーを返却
4. 取得結果（`UserRow`）を返却

### User編集
#### 概要

サイト利用者のプロフィール情報を更新する。

#### 処理フロー

1. 更新対象の User ID を受け取る
2. リクエスト（`UpdateUserRequest`）の検証
    - 名前: 必須・30文字以内
    - 自己紹介文: 任意・200文字以内
    - URL系: 空文字は `null` に変換
3. DB から対象ユーザーを検索
4. 存在しない場合はエラーを返却
5. ユーザー名の重複チェック（自分自身は除外）
6. 永続化用モデル（`UserRow`）の組み立て（`updatedAt` を更新）
7. DB へ保存
8. 更新結果を返却

### User削除
#### 概要

サイト利用者のプロフィールを削除する。

#### 処理フロー

1. 削除対象の User ID を受け取る
2. DB から対象ユーザーを検索
3. 存在しない場合はエラーを返却
4. DB から削除
5. 削除結果を返却
