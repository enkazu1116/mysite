# ユーザー表示・管理画面

## 概要

ユーザー情報の表示画面がトップページを想定している。
ユーザー情報の表示・編集に関わるコンポーネントを定義する。

## コンポーネント一覧

| コンポーネント | 責務 |
|-------------|-------------|
| プロフィール | 登録プロフィールの表示 |
| 編集ボタン | プロフィール編集画面切り替え・管理者のみ |
| GitHub連携状態表示 | GitHub連携状態確認 |
| 他アウトプット | 他アウトプットのURLと説明 |
| 関連サイト | 他サービスのURL |

## 各コンポーネント詳細
### プロフィール
表示するプロフィールは以下の通り。

| 表示内容 | 説明 |
|-------------|-------------|
| 名前    | ユーザー名 |
| アイコン |  |
| BIO | 自己紹介文 |
| GitHub | カレンダー上でのGitHubのコミット状況の表示 |

### 編集ボタン
編集ボタンを押下後、編集設定画面を表示。管理者以外は表示されない。<br />
編集設定画面の各項目を以下に記載する。<br />
[ユーザー編集画面]()

### GitHub
カレンダー形式でのコミット状況を確認できるコンポーネント。<br />
HeroUIのカレンダーを使用して表す。<br />
イベント = コミットとして扱い、コミットがあればカレンダー上で表示される。

### 他アウトプット
まだ他アウトプットが未完であるため、将来的な機能追加。

### 記事サイト
- Zennを使用しているので、そこに遷移できるアイコン
- GitHubのアイコンと自分のアカウントへの遷移
