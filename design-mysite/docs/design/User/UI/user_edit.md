# ユーザー編集画面

## 概要
ユーザーのプロフィール設定を行う画面。
内容が少ないので、モーダルで編集する。

## モーダル画面
### 詳細

| 構成 | 説明 | バリデーション |
|-------------|-------------|-------------|
| タイトル | プロフィール編集 |  |
| アイコン | アイコンプレビューと画像のパス設定<br />未設定時はデフォルト画像 | 将来追加機能 |
| ユーザー名 | フォーム | 文字数30文字以内 |
| BIO | テキストエリア | 文字数200文字以内 |
| GitHub連携 | フォーム | |
| 記事サイト | フォーム | |
| ポートフォリオ | フォーム | 将来想定 |
| 送信ボタン | 入力内容の送信 | |
| 保存ボタン | 入力内容の保存 | |
| 閉じるボタン | モーダルを閉じる。入力内容がある場合は、警告メッセージの表示 | |

### 検討事項
モーダルで作成するが、GitHub連携の詳細がより明確になったときにモーダルで良いのかを検討する。
重たい場合は、別のコンポーネントを検討する必要がある。
