# ユーザードメイン

## 概要

ユーザードメインのエンティティ・責務・境界を定義する。

## エンティティ

| エンティティ | 説明 |
|--------------|------|
| User | プロフィール・自己紹介を持つ管理者ユーザー |
| AuditMetadata | システム監視情報 |

### エンティティ詳細

**User**
| フィールド | 説明 | 
|--------------|------|
| user_name | ユーザーの名前 |
| bio | 自己紹介文 |
| icon_url | 未設定時:デフォルト画像使用 |

**AuditMetadata**
| フィールド | 説明 | 
|--------------|------|
| created_at | 作成日時 |
| updated_at | 更新日時 |

管理者の自己更新のみを想定するため、作成者・更新者は持たない。
