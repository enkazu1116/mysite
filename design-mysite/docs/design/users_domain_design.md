# Users Domain 設計メモ

## 目的

システム開発者の自己紹介・ブログ用途のため、ユーザーはシステム開発者のみを想定する。

ユーザードメインの責務:

- プロフィール情報の管理
- 自己紹介文の管理
- 技術スキル・参画プロジェクトへの参照（関連ドメインとの連携）

## スコープ

| 含む | 含まない（現時点） |
|------|-------------------|
| ユーザー基本情報（名前・プロフィール） | 複数ユーザー・一般公開登録 |
| プロフィール表示用 API | ソーシャルログイン |
