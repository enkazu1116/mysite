# プロジェクト概要

## 目的

- 自身の簡単な自己紹介
- 技術スキル
- 読書記録
- 参画プロジェクト

基本的にサイト内で簡単に時間をかけずに管理が行えることを目的とする。

## マイルストーンと利用者想定

1. 開発初期は開発者のみが管理することができ、訪問者は閲覧のみを可能とする。
2. 全て完了後に、ゲストユーザーとしてシステムを体験できるようにする。
3. 他のポートフォリオと連携して、他のポートフォリオへの窓口とする。

## ドキュメント構成

設計・技術ノートの 2 区分で一元管理する。

| 区分 | 管理対象 | 入口 |
|------|----------|------|
| ドメイン設計 | DB・画面・ドメイン・型・API の設計 | [ドメイン設計](/docs/category/ドメイン設計) |
| 技術ノート | 実装方針・技術選定・課題の記録 | [技術ノート](/docs/tech/tech_index) |

### ドメイン設計のフォルダ構成

各ドメイン（User / Books / Skills）は同じ構成でドキュメントを置く。

| フォルダ | 内容 |
|----------|------|
| インデックス | ドメインの目的・全体像 |
| DB | テーブル定義・カラム仕様 |
| UI | コンポーネント単位の画面設計 |
| Domain | エンティティ・責務・境界 |
| Type | Type・Interface 定義 |
| API | エンドポイント定義 |
