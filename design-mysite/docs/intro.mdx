# プロジェクト概要

## 目的

自身の簡単な自己紹介と、参画してきたプロジェクトや読んできた本を紹介するサイトを構築する。
また、自身が記載した記事の紹介も行いたい。
基本的にサイト内で簡単に時間をかけずに行えることを目的とする。

## 北極星

> **ポートフォリオをコードで運用するバックエンド**

静的なページではなく、**自分専用のミニ CMS + 公開 API** として運用する。

| 利用者 | 役割 |
|--------|------|
| 訪問者 | 読み取り専用 API（Skills / Projects / Books） |
| 本人 | 管理 API（認証付きで更新） |
| 将来 | GitHub 連携・読書ログなど外部と同期する機能 |

## ドキュメント構成

このサイトでは設計・技術的課題・ノートを一元管理する。

| セクション | 内容 |
|------------|------|
| [ドメイン設計](/docs/category/ドメイン設計) | Users / Books / Skills 各ドメインの設計メモ |
| [DB設計](/docs/category/db設計) | テーブル定義・カラム仕様 |
| [技術ノート](/docs/category/技術ノート) | 実装方針・技術選定・課題の記録 |
